# ПравилаНативныхОшибок

Возвращает встроенный набор правил, который сопоставляет исключения объектов
OneScript с кодами [`КодыНативныхОшибок`](КодыНативныхОшибок.md).

## Создание

```bsl
Новый ПравилаНативныхОшибок
```

Создает каталог правил файловой системы, процессов, потоков, JSON, XML, ZIP,
текста, двоичных данных, HTTP, прокси, сети, объектов, коллекций и других
встроенных возможностей OneScript.

## Методы

### Все

```bsl
.Все()
```

Возвращает набор правил нативного каталога.

#### Возвращаемое значение

`ФиксированныйМассив` из
[`ПравилоКлассификацииОшибок`](https://github.com/Stivo182/oscript-errors/blob/main/docs/ПравилоКлассификацииОшибок.md).

## Использование

Зарегистрируйте тип каталога как поставщика правил в общем
[`КлассификаторОшибок`](https://github.com/Stivo182/oscript-errors/blob/main/docs/КлассификаторОшибок.md):

```bsl
#Использовать errors
#Использовать native-errors

Классификатор = Новый КлассификаторОшибок;
Классификатор.ДобавитьПоставщикаПравил(Тип("ПравилаНативныхОшибок"));
```

При регистрации типа каталог создается лениво: при первой классификации.

Дополнительные наборы правил участвуют в общем выборе по силе совпадения и
приоритету.

Если нужна сама коллекция правил для перебора, инспекции или выбора отдельных
правил, получите ее напрямую:

```bsl
Правила = Новый ПравилаНативныхОшибок().Все();
```
