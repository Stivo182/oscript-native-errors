# ПравилаНативныхОшибок

Возвращает встроенный набор правил, который сопоставляет исключения объектов
OneScript с кодами [`КодыНативныхОшибок`](КодыНативныхОшибок.md).

## Создание

```bsl
Новый ПравилаНативныхОшибок
```

Создает каталог правил файловой системы, процессов, потоков, JSON, XML, ZIP,
текста, двоичных данных, HTTP, прокси, сети, объектов, коллекций и других
встроенных возможностей OneScript.

## Методы

### Все

```bsl
.Все()
```

Возвращает набор правил нативного каталога.

#### Возвращаемое значение

`ФиксированныйМассив` из
[`ПравилоКлассификацииОшибок`](https://github.com/Stivo182/oscript-errors/blob/main/docs/ПравилоКлассификацииОшибок.md).

## Использование

Зарегистрируйте тип каталога как поставщика правил в общем
[`КлассификаторОшибок`](https://github.com/Stivo182/oscript-errors/blob/main/docs/КлассификаторОшибок.md):

```bsl
#Использовать errors
#Использовать native-errors

Классификатор = Новый КлассификаторОшибок;
Классификатор.ДобавитьПоставщикаПравил(Тип("ПравилаНативныхОшибок"));
```

При регистрации типа каталог создается лениво: при первой классификации.

Дополнительные наборы правил участвуют в общем выборе по силе совпадения и
приоритету.

Если нужна сама коллекция правил для перебора, инспекции или выбора отдельных
правил, получите ее напрямую:

```bsl
Правила = Новый ПравилаНативныхОшибок().Все();
```

## Входящие запросы Kestrel

При чтении `Контекст.Запрос.Тело` распознаются превышение размера,
повреждение, обрыв, таймаут тела и ошибки завершающих заголовков.
Ошибки начальной строки и заголовков, отклоненные до вызова обработчика,
недоступны классификатору.

При формировании ответа распознаются превышение `ДлинаКонтента`, запись тела
для запрещающего ее статуса, недопустимый заголовок и изменение ответа после начала отправки.

Классификация не меняет HTTP-ответ. В блоке `Исключение` обработчика
с настроенным выше классификатором код превышения размера можно сопоставить с 413:

```bsl
НормализованнаяОшибка = Классификатор.Классифицировать(ИнформацияОбОшибке());
Если НормализованнаяОшибка <> Неопределено Тогда
    Снимок = Новый СнимокКадраОшибки(НормализованнаяОшибка);
    Если Снимок.КодОшибки() = КодыНативныхОшибок.HTTPТелоЗапросаСлишкомБольшое()
        И Не Контекст.Ответ.Начат И Не Контекст.ЗапросПрерван Тогда
        Контекст.Ответ.КодСостояния = 413;
        Контекст.Ответ.Записать("Превышен допустимый размер тела запроса");
        Возврат;
    КонецЕсли;
КонецЕсли;
ВызватьИсключение;
```

Поддерживаются цепочки `.Причина` и текстовые обертки исходной нативной ошибки.
Для составной ошибки передавайте саму `ИнформацияОбОшибке`: ее подробное
текстовое представление может не сохранить причину.
