# КодыНативныхОшибок

Модуль `КодыНативныхОшибок` возвращает стабильные строковые коды. Используйте
его функции вместо строковых литералов при сравнении и создании ошибок.

```bsl
Если ДиагностикаОшибок.КодОшибки(Ошибка) = КодыНативныхОшибок.JSONНекорректныйСинтаксис() Тогда
    Сообщить("JSON содержит синтаксическую ошибку");
КонецЕсли;
```

## Методы

### Все

```bsl
Коды = КодыНативныхОшибок.Все();
```

Возвращает все коды модуля.

#### Возвращаемое значение

`ФиксированныйМассив` со стабильными машинными кодами ошибок.

## Коды

Колонка «Объекты OneScript» описывает область действия текущих правил и приводит
характерные объекты и операции. Если правило основано на общем типе исключения или
стандартном сообщении движка, оно распространяется и на другие объекты с той же ошибкой.
